react-brackets draws tournament brackets from plain data. It handles the hard parts, like seeding, byes, results, layout, connector lines and small screens, and leaves the look to you.

<Preview>
  <QuickStartDemo />
</Preview>

```tsx title="app.tsx"
import { Bracket, singleElimination } from 'react-brackets';
import '@react-brackets/theme/theme.css';

const stage = singleElimination([
  { id: 'falcons', name: 'Falcons' },
  { id: 'wolves', name: 'Wolves' },
  // …
]);

export function App() {
  return <Bracket stage={stage} />;
}
```

## How it fits together

## Packages

| Package | What it is |
| --- | --- |
| `react-brackets` | The React components. Re-exports everything from the core. |
| `@react-brackets/core` | Formats, results, standings and layout. No framework, no dependencies. |
| `@react-brackets/theme` | An optional stylesheet driven by CSS variables. |
