```tsx
import { Bracket, singleElimination } from '@react-brackets/native';

const stage = singleElimination(teams);

export function Screen() {
  return <Bracket stage={stage} />;
}
```

That one line draws everything in the recording: the rounds and their lines, a tab for each round under the paged view, and zoom buttons when the whole tree is pinched and zoomed. Each of those is a part you can restyle, move or replace, for example to [put the round tabs above the bracket](/docs/native/navigation-and-zoom#above-the-bracket-or-not-at-all).

## How it moves

Every card's place on every round is worked out up front. A swipe only moves one number on the UI thread, and the cards, round titles, connector lines and the bracket's height all follow that number there, in the same frame. React hears about the new round once the swipe lands, so nothing re-renders while your finger is down.

Connector lines are plain views moved by the same transforms as the cards. They never trail behind during a fast swipe, and they stay sharp at any zoom.

## What you get

- **Every format**: single and double elimination, round robin, Swiss and your own data, with [results and live scores](/docs/native/results) that move winners on.
- **Two phone layouts**: a bracket with the next round peeking in, or [plain lists](/docs/native/layouts#plain-lists), one round at a time.
- **The whole tree** on wider screens, [scrolled, fitted or pinched and zoomed](/docs/native/layouts#the-whole-tree).
- **[Right to left](/docs/native/right-to-left)**, for Arabic, Hebrew and Persian, with every built-in label translatable.
- **Your own look**: a [light and dark theme](/docs/native/theme), [a style on every part](/docs/native/styling) for StyleSheet, Uniwind, NativeWind or Unistyles, and [your own match cards](/docs/native/match-cards).
- **Headless when you want it**: round tabs and zoom buttons are parts you can [restyle, move or replace](/docs/native/navigation-and-zoom), every swipe and zoom behaviour is an option, and the whole bracket can be [built from parts](/docs/native/building-from-parts).

Start with [installation](/docs/native/installation), or see it all in the [examples](/examples/native).
