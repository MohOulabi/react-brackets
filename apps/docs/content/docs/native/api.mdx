```tsx

<Bracket stage={stage} />;
```

`@react-brackets/native` also exports everything from [`@react-brackets/core`](/docs/api/formats): the formats, `reportResult`, `standings` and the data types work the same way as on the web. Hooks, options and types are in [Hooks and types](/docs/native/hooks-and-types).

## `<Bracket>`

Draws every group of a stage, each with its title, its rounds and its round tabs. A double elimination stage gets its winners bracket, with the grand final, and its losers bracket below it. It's a shortcut for the parts below: see [Building from parts](/docs/native/building-from-parts) for what it puts together.

<ApiTable from="native" name="BracketProps" />

```tsx
// Paging and highlighting held in your own state
<Bracket stage={stage} page={page} onPageChange={setPage} highlighted={team} onHighlightChange={setTeam} />

// Plain lists, one round per swipe
<Bracket stage={stage} compact="list" maxSwipeRounds={1} />

// The whole tree on a phone, to pinch and zoom, up to three times
<Bracket stage={stage} compactBelow={0} mode="pan-zoom" zoom={{ maxScale: 3 }} />

// Right to left, translated
<Bracket stage={stage} dir="rtl" labels={{ tbd: 'لم يحدد', bye: 'راحة' }} />
```

## `Bracket.Root`

Holds one group's state: the page, the highlight, the theme, card heights, and pan and zoom. Every other part goes inside it. Without children it draws the group title, the viewport and the round tabs, like `<Bracket>` does for one group.

```tsx
<Bracket
  stage={stage}
  renderMatch={() => (
    <Bracket.Match style={({ live }) => [styles.card, live && styles.live]}>
      <Bracket.Participant slot={0}>
        {({ participant, slot, winner }) => (
          <Text style={winner && styles.winner}>
            {participant?.name} {slot.score}
          </Text>
        )}
      </Bracket.Participant>
      <Bracket.Participant slot={1} />
    </Bracket.Match>
  )}
/>
```

## `Bracket.RoundTitle`

The default title above a round, given the `round`. Use it inside `renderRoundTitle` to keep the default look next to something of your own. See [Round titles](/docs/native/round-titles).

## Theme

`theme` on `<Bracket>` or `Bracket.Root` replaces any value of the light or dark theme, picked from the system's appearance. `BracketThemeProvider` sets one theme for every bracket below it, and `createTheme` builds one from a base. See [Theme](/docs/native/theme).

```tsx
import { BracketThemeProvider, createTheme, darkTheme } from '@react-brackets/native';

const theme = createTheme({ colors: { accent: '#ea580c' }, radius: 14 }, darkTheme);

<BracketThemeProvider theme={theme}>
  <App />
</BracketThemeProvider>;
```
