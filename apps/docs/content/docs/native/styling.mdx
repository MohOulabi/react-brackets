## Theme

Light and dark themes follow the device. Change any value on one bracket, or for all of them:

```tsx
import { BracketThemeProvider, createTheme, darkTheme } from '@react-brackets/native';

<Bracket stage={stage} theme={{ colors: { accent: '#ea580c' }, radius: 14 }} />;

const court = createTheme({ colors: { accent: '#d7f25a', surface: '#142b63' } }, darkTheme);

<BracketThemeProvider theme={court}>{/* every bracket inside */}</BracketThemeProvider>;
```

| Value | Used for |
| --- | --- |
| `colors.text`, `colors.textMuted` | Names, losers and slots still to be decided |
| `colors.surface`, `colors.surfacePressed`, `colors.border` | Match cards |
| `colors.line` | Connector lines |
| `colors.accent`, `colors.accentSoft` | Winner scores, the highlighted path, the current round |
| `colors.live` | The border of a live match |
| `radius`, `lineWidth`, `connectorRadius` | Corners, line width and rounded line turns |
| `matchWidth`, `matchGap`, `columnGap`, `pagedColumnGap`, `titleHeight` | Sizes, in points |
| `fontFamily`, `fontSize`, `titleFontSize` | Text |

## Your own cards

Every part takes a `style`, or a function of its state. `Bracket.Participant` also takes a function as its child, to draw anything from the participant:

```tsx
<Bracket
  stage={stage}
  renderMatch={() => (
    <Bracket.Match style={({ live }) => [styles.card, live && styles.live]}>
      {([0, 1] as const).map((slot) => (
        <Bracket.Participant key={slot} slot={slot}>
          {({ participant, slot: { score }, winner }) => (
            <>
              <Text style={[styles.name, winner && styles.winner]}>{participant?.name}</Text>
              <Text style={styles.score}>{score}</Text>
            </>
          )}
        </Bracket.Participant>
      ))}
    </Bracket.Match>
  )}
/>
```

The match state has `live`, `completed` and `highlighted`. The participant state has `participant`, `slot`, `winner`, `loser`, `bye`, `empty` and `highlighted`. The [Nations example](/docs/native/examples#nations) builds a full card this way.

Tapping a participant highlights their path. Pass `highlighted` and `onHighlightChange` to control it, or `onMatchPress` to make whole matches pressable instead.

## Tailwind, through Uniwind or NativeWind

Wrap a part to give it a `className`, and use classes freely inside `renderMatch`:

```tsx
import { withUniwind } from 'uniwind';

const Match = withUniwind(Bracket.Match);

<Bracket
  stage={stage}
  renderMatch={() => (
    <Match className="rounded-2xl border-indigo-200 bg-white dark:bg-indigo-900">{/* … */}</Match>
  )}
/>;
```

With NativeWind, wrap the part with `cssInterop` the same way. See the [Tailwind example](/docs/native/examples#tailwind).

## Unistyles

`withUnistyles` maps your Unistyles theme onto the bracket's, and keeps it in step when the theme changes:

```tsx
import { withUnistyles } from 'react-native-unistyles';

const ThemedBracket = withUnistyles(Bracket, (theme) => ({
  theme: { colors: theme.bracket, radius: 14 },
}));
```

See the [Unistyles example](/docs/native/examples#unistyles).
