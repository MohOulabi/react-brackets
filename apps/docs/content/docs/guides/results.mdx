Stages are immutable. Every update returns a new stage, so they drop straight into `useState`, a store, or a server response.

<Tabs groupId="platform" persist items={['React', 'React Native']}>
<Tab value="React">

```tsx
import { reportResult, resetResult } from 'react-brackets';

const [stage, setStage] = useState(() => singleElimination(teams));

// a finished match: the higher score wins and moves on
setStage((s) => reportResult(s, 'main.r1.m1', { scores: [3, 1] }));

// a live match: scores show, nobody advances yet
setStage((s) => reportResult(s, 'main.r1.m2', { scores: [1, 1], live: true }));

// a tie in a knockout needs an explicit winner
setStage((s) => reportResult(s, 'main.r1.m2', { scores: [2, 2], winner: 1 }));

// undo, which also clears everything that depended on it
setStage((s) => resetResult(s, 'main.r1.m1'));
```

## Match status

| Status | Meaning |
| --- | --- |
| `waiting` | At least one side is still to be decided. |
| `ready` | Both sides are known. |
| `live` | Reported with `live: true`. |
| `completed` | Finished. A bye completes on its own. |
| `skipped` | Will never be played, like an unused bracket reset. |

Overturning a result clears every result downstream of it, so a stage can't hold a winner who never qualified.

## Frequent updates

An update keeps every match it didn't change as the same object. On the web, only the cards whose match changed render again, as long as `renderMatch` keeps its identity: define it outside your component, or wrap it in `useCallback`. A new function on every render still works, but it redraws every card, which you'll feel on brackets with hundreds of matches.

```tsx
const renderMatch = (match: Match) => <MatchCard match={match} />;

function Tournament() {
  const [stage, setStage] = useState(() => singleElimination(teams));
  return <Bracket stage={stage} renderMatch={renderMatch} />;
}
```

## Saving stages

A stage is JSON. Store it, send it, and render it anywhere:

```ts
await db.save(JSON.stringify(stage));
const stage = JSON.parse(saved) as Stage;
```
