Set `dir="rtl"` on the bracket or any parent. The tree, connector lines, swipe direction, arrow keys and pagination all flip.

<Tabs groupId="platform" persist items={['React', 'React Native']}>
<Tab value="React">

```tsx
<div dir="rtl" lang="ar">
  <Bracket
    stage={singleElimination(clubs, { roundName: (index) => arabicRoundNames[index] })}
    labels={{ tbd: 'لم يحدد', bye: 'تأهل مباشر', previous: 'الجولة السابقة', next: 'الجولة التالية' }}
  />
</div>
```

## Labels

| Label | Default |
| --- | --- |
| `tbd` | `TBD` |
| `bye` | `Bye` |
| `previous` / `next` | `Previous round` / `Next round` |
| `rounds` | `Rounds` |
| `zoomIn` / `zoomOut` / `zoomReset` | `Zoom in` / `Zoom out` / `Fit to view` |

Round names come from `roundName` on each format, and group names from `groupName` on `roundRobin`.
