## A custom match

`renderMatch` swaps the match card and keeps everything else, including lines, paging, highlighting and clicks:

<Preview>
  <CustomMatchDemo />
</Preview>

```tsx
<Bracket
  stage={stage}
  renderMatch={(match) => (
    <Bracket.Match className="w-60 rounded-xl border bg-card">
      <header className="border-b px-3 py-1.5 text-xs">{match.status}</header>
      {([0, 1] as const).map((slot) => (
        <Bracket.Participant key={slot} slot={slot} className="flex gap-2 px-3 py-2">
          {({ participant, winner, slot: { score } }) => (
            <>
              <Avatar name={participant?.name} />
              <span className={winner ? 'font-semibold' : ''}>{participant?.name ?? 'TBD'}</span>
              <span className="ms-auto tabular-nums">{score ?? '–'}</span>
            </>
          )}
        </Bracket.Participant>
      ))}
    </Bracket.Match>
  )}
/>
```

Keep `<Bracket.Match>` as the outer element. Connector lines attach to it, and it carries the data attributes and click handling. Your own data is on `match.meta` and `participant.meta`.

## Composing every part

`<Bracket>` is a shortcut. Compose the parts yourself for full control over the markup:

```tsx
<Bracket.Root stage={stage} onMatchClick={open}>
  <Bracket.GroupTitle />
  <Bracket.Viewport mode="pan-zoom">
    <Bracket.Rounds>
      {(column) => (
        <Bracket.Round>
          <Bracket.RoundTitle>{column.round.name}</Bracket.RoundTitle>
          <Bracket.Matches>{(match) => <MyMatch match={match} />}</Bracket.Matches>
        </Bracket.Round>
      )}
    </Bracket.Rounds>
    <Bracket.Connectors radius={8} />
  </Bracket.Viewport>
  <Bracket.Pagination />
</Bracket.Root>
```

`Bracket.Root` draws one group. `<Bracket>` draws every group of a stage, like the winners and losers brackets. Inside any part, `useBracket()` gives you the layout, the participants and the paging state.
