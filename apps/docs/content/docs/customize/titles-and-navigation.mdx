## Round titles

`Bracket.RoundTitle` shows the round's name. Give it children to show anything else, like a date or the match format. Compose the rounds to reach it:

<Preview>
  <RoundTitlesDemo />
</Preview>

```tsx
<Bracket.Root stage={stage}>
  <Bracket.Viewport>
    <Bracket.Rounds>
      {(column, index) => (
        <Bracket.Round>
          <Bracket.RoundTitle className="flex flex-col">
            <span>{column.round.name}</span>
            <span className="text-xs">{schedule[index]}, best of {index === 2 ? 5 : 3}</span>
          </Bracket.RoundTitle>
          <Bracket.Matches />
        </Bracket.Round>
      )}
    </Bracket.Rounds>
    <Bracket.Connectors radius={8} />
  </Bracket.Viewport>
</Bracket.Root>
```

`column.side` tells you which half of a [mirrored layout](/docs/guides/layouts) the column is on, and `column.current` whether it's the round in focus on a phone.

To only rename rounds, there's no need to compose: pass `roundName` when you build the stage, as in `singleElimination(teams, { roundName: (index, total) => … })`.

## Group titles

`Bracket.GroupTitle` names the group, like `Losers bracket`. Children replace the name:

```tsx
<Bracket.GroupTitle>
  {group.name} <span className="text-muted-foreground">{group.rounds.length} rounds</span>
</Bracket.GroupTitle>
```

Inside the root, `useBracket().group` gives you the group being drawn.

## A round title with navigation

On narrow containers the bracket shows one round at a time, with `Bracket.Pagination` underneath. A title above the bracket can carry the navigation instead, built from `usePagination()`:

<Preview>
  <Phone>
    <CustomPaginationDemo />
  </Phone>
</Preview>

```tsx
function RoundStepper() {
  const { rounds, page, previous, next, canPrevious, canNext } = usePagination();
  return (
    <div className="flex items-center gap-3">
      <button disabled={!canPrevious} onClick={previous}>Previous</button>
      <span>{rounds[page]?.name}</span>
      <button disabled={!canNext} onClick={next}>Next</button>
    </div>
  );
}

<Bracket.Root stage={stage}>
  <RoundStepper />
  <Bracket.Viewport>
    <Bracket.Rounds />
    <Bracket.Connectors />
  </Bracket.Viewport>
</Bracket.Root>
```

Pills that slide under the round in focus, dots, tabs, and every part involved are in [navigation and zoom](/docs/customize/navigation-and-zoom).

## Labels

Every built-in string, like `TBD`, `Bye` and the button names read by screen readers, can be changed through `labels`. See [RTL and languages](/docs/guides/rtl-and-languages).
