## useBracket

```ts
function useBracket(): BracketContextValue
```

Everything about the bracket being drawn. Call it in any component inside `Bracket.Root`, for example to build your own navigation:

```tsx
function RoundPicker() {
  const { rounds, page, setPage } = useBracket();
  return (
    <select value={page} onChange={(event) => setPage(Number(event.target.value))}>
      {rounds.map((round, index) => (
        <option key={round.id} value={index}>{round.name}</option>
      ))}
    </select>
  );
}
```

## useBracketCell

```ts
function useBracketCell(): LayoutCell
```

The match being rendered and where it sits, inside `Bracket.Matches`. Returns a [`LayoutCell`](/docs/api/utilities#layoutcell).

## useConnector

```ts
function useConnector(): ConnectorState
```

The line being rendered, inside `Bracket.Connectors`. Use it to keep a custom line in its own component. Returns a [`ConnectorState`](#connectorstate).

## usePagination

The paged view's rounds and position, and actions to move it, anywhere inside `Bracket.Root`. See [navigation and zoom](/docs/customize/navigation-and-zoom#anything-else-from-usepagination).

```tsx
const { rounds, page, position, setPage, previous, next, canPrevious, canNext, paged } = usePagination();
```

## useZoom

The zoom of the pan and zoom viewport, and actions to change it, anywhere inside `Bracket.Root`. `null` while the bracket isn't showing a pan and zoom viewport. See [navigation and zoom](/docs/customize/navigation-and-zoom#a-toolbar-with-a-slider).

```tsx
const zoom = useZoom();
zoom?.zoomTo(zoom.maxScale);
```

## ClassNames

A class for any part, by name:

```ts
type ClassNames = Partial<Record<Part, string>>;
```

`Part` is one of `root`, `group-title`, `viewport`, `content`, `round`, `round-title`, `matches`, `cell`, `match`, `participant`, `participant-name`, `participant-score`, `connectors`, `connector`, `pagination`, `page`, `page-previous`, `page-next`, `zoom-controls`, `zoom-in`, `zoom-out` and `zoom-reset`. See [Parts and data attributes](/docs/styling/data-attributes) for what each one is.
