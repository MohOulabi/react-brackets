Leagues that split into a championship group and a relegation group, like the Scottish Premiership. `roundRobin` takes any number of `legs`, and `groups` can be the groups themselves as lists of participant ids. `standings` takes a `carryOver` table from an earlier phase, so points from before the split count. See the new "League with a split" page.
