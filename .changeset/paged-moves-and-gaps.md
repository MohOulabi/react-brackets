Smoother paged view on phones. A card that grows by itself, like a roster opening with a CSS transition, no longer makes the bracket run the same move twice, resizing the window no longer animates the cards, and a card wider than its round's column no longer spills over the next round: the theme keeps cards within their column, so the gap between rounds always holds.
